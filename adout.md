1) Что такое Git и для чего он нужен?
Гит нужен для совместной работы между людьми. Позволяет работать над одним проектам нескольким людям 
2) Что такое репозиторий в Git
Это папка проекта, в которой отслеживаются все файлы и видна история изменений
3) В чём разница между централизованными и распределёнными системами контроля версий?
Централизированный 
1. Имеет один главный сервер со всей историей проекта
2. У каждого разработчика хранятся актуальные файлы
3. Если главный сервер падает, работа останавливается, и историю временно нельзя восстановить.
Распределенный
1. У каждого разработчика на компьютере хранится полная копия всего репозитория со всей историей.
2. Интернет нужен только для обмена изменениями с другими.
3. Если сервер сломается, проект можно восстановить с любого рабочего компьютера
