1 git clone — копирует существующий удаленный репозиторий на ваш компьютер со всей его историей.
2 git status — показывает текущее состояние рабочего каталога: измененные, новые или подготовленные к коммиту файлы.
3 git add — добавляет измененные или новые файлы в индекс (staging area) для подготовки к сохранению.
4 git commit — создает снимок текущего состояния файлов из индекса и сохраняет его в истории локального репозитория.
5 git push — отправляет ваши локальные коммиты в удаленный репозиторий
6 git init — создает новый пустой репозиторий Git в текущей папке
7 git pull — скачивает изменения из удаленного репозитория и сразу объединяет их с вашей текущей веткой.
8 git fetch — скачивает изменения и историю из удаленного репозитория, но не объединяет их с вашими файлами.
9 git branch — показывает список всех веток в проекте, а также позволяет создавать новые ветки или удалять их.
10 git checkout (или git switch) — переключает вас между существующими ветками проекта или позволяет вернуться к более ранним состояниям файлов.
